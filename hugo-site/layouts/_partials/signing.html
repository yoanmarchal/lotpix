Code signing policy

Politique de signature

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Ce qui est signé

L'application Windows (lotpix.exe) et son installeur sont compilés et signés par le workflow de release GitHub Actions, uniquement à partir du code de ce dépôt. Chaque signature est validée à la main avant d'être appliquée. Les versions publiées avant la mise en place de la signature ne sont pas signées.

Confidentialité

Lotpix traite les images sur votre ordinateur : aucune image, aucun nom de fichier ni aucune donnée d'usage n'est envoyé. Le seul accès réseau est la recherche d'une nouvelle version au démarrage, qui interroge l'API des releases GitHub ; elle se désactive par la case « Vérifier les mises à jour » en bas de la fenêtre. Cette requête est soumise à la politique de confidentialité de GitHub.
